# Contexto do projeto

O **tabnews-ia** é uma implementação do TabNews desenvolvida com o auxílio de agentes de IA.

## Tecnologias

- Next.js, com App Router.
- React.
- JavaScript e JSX.

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm start`: inicia o servidor de produção após o build.

## Manutenção deste contexto

Mantenha neste arquivo apenas orientações duradouras e úteis em diferentes sessões e tarefas. Consulte os arquivos do projeto para verificar versões, estrutura, scripts disponíveis e funcionalidades implementadas.
